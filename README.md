# git-web-clone

This repository was created while learning **Git** and **GitHub** through tutorials and hands-on practice. It serves as a personal workspace where I explored the fundamentals of version control and learned how to manage code efficiently using Git.

## 📖 About

The purpose of this repository is to practice common Git workflows and understand how developers use version control in real-world software development. Throughout this project, I experimented with various Git commands, repository management techniques, and GitHub features to strengthen my understanding of collaborative development.

## 🎯 What I Practiced

* Initializing Git repositories
* Configuring Git username and email
* Cloning repositories
* Creating and modifying files
* Staging changes with `git add`
* Creating commits with `git commit`
* Viewing commit history
* Working with branches
* Merging branches
* Connecting local repositories to GitHub
* Pushing and pulling changes
* Understanding the difference between HTTPS and SSH authentication
* Managing remote repositories

## 🛠 Technologies Used

* Git
* GitHub
* Markdown
* Visual Studio Code
* Command Line (Git Bash/Terminal)

## 📚 Purpose

This repository is intended for learning and practice purposes only. It documents my progress as I build a strong foundation in Git and GitHub, helping me become more comfortable with version control workflows used in software development.

As I continue learning, I plan to update this repository with additional examples, commands, and best practices.
